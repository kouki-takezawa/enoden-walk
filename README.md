# 江ノ電 鎌倉高校前 散歩

夕暮れの江ノ電・鎌倉高校前駅の **1号踏切** と国道134号、相模湾の見える丘の街を、**人物を操作して歩き回れる** 3D ウェブアプリです（Three.js）。
踏切は電車が来ると警報が鳴り、遮断機が下り、江ノ電が走り抜けます。**駅のホームから電車に乗って**車窓の景色も楽しめます。昼・夕方・夜の切り替えと写真モード付き。

**▶ 遊ぶ: https://enoden-walk.vercel.app**

- 警報中（カンカンカン）は踏切に入れません。踏切内にいると外へ押し出され、線路に立っていると電車に弾かれて路肩へ戻されます。
- **ホームへは西端のスロープから上がれます**（ミニマップのオレンジの点、名所メニューの「ホーム入口」）。駅の名所へ移動すると、ホームの上に直接降り立ちます。
- 駅のホームで電車が停まっている間（約 20 秒）に `E` で乗車。窓の外を眺められます（壁は透けて、車窓の景色が全周見えます）。終点で折り返してホームへ戻ります。
- 右上の ⚙ から画質（自動 / 低 / 中 / 高）、音量、視点操作、言語（日本語 / English）、動きを抑える設定などを変更でき、`localStorage` に保存されます。

## 仕組み

- **フロント**: Vite + Three.js。
  - `main.js` … 読み込み・ループ・カメラ（衝突・FOV）・乗降・撮影　`ui.js` … HUD / メニュー / ミニマップ / 写真モード
  - `input.js` … キー・マウス・タッチ・ゲームパッド　`player.js` … 歩行・走行・ジャンプ、アニメーションの速度ブレンド
  - `train.js` … ダイヤ・踏切・乗客　`ground.js` … 歩ける高さ・表面・固体セル　`config.js` … 品質プリセット・設定・文言
  - `fx.js` … 壁 / 地形 / 路面のシェーダ拡張　`sky.js` … 空・時刻・街灯　`sea.js` … 海　`trees.js` … 木　`render.js` … レンダラ + ポストエフェクト　`audio.js` … 音
- **描画**: sRGB 出力 + ACES Filmic、太陽 / 月の `DirectionalLight` によるプレイヤー追従のソフトシャドウ（テクセルにスナップ）、空のシェーダから作る PMREM 環境マップ（時刻に応じて更新）、glTF マテリアルの PBR 調整。
- **モデル**（`public/models/`）: Blender で手続き生成したシーンを書き出したもの。
  - `world.glb`（Draco、約 4 MB）: 地形・建物・線路・駅・踏切・電柱と電線・遠景　`train.glb`: 江ノ電 1000 形（2 両）　`character.glb`: 20 代日本人男性（サブディバイド・Draco、ボーン 56、Idle / Walk / Run / Sprint / Jump をベイク）
  - `ground.bin`（高さ）/ `surface.bin`（路面の種類）/ `solid.bin`（柵・電柱などの細い障害物）: 1 m 格子　`trees.json`（木）/ `meta.json`（プラットホーム・踏切・街灯・名所）
- 手続きノードのマテリアルは glTF に載らないため、書き出し時に **材質ごとの平均色 + 頂点カラー** へ焼き込み、建物は頂点アルファに窓の種別コードを入れて JS 側で窓を描きます。

### 既知の制約・割り切り

- 環境遮蔽は Blender で焼いた頂点 AO（リアルタイム GTAO ではない）。影は 1 枚のシャドウマップ（CSM なし）。
- 電車の車輪は回転せず、足の IK もありません（足は地面の高さに合わせるだけ）。
- 乗車中の車内は壁を透かして見せる簡易表現です（座席の着席アニメーションはありません）。
- 建物の中には入れません。
- 当たり判定の格子（1 m）ではホームの床が柵・ベンチで埋まってしまうため、読み込み時にホーム床の通行不可を解除しています（線路側の縁と北側の柵は塞いだまま）。`tests/reach.test.js` が、全名所とホーム全域に歩いて到達できることを検査します。
- 共有ボタンのリンクには、いる場所・視点・時刻が入ります（`?x=&z=&yaw=&cy=&cp=&t=`）。
- 水際に降りることはできない（海面より 1.4 m 以上高い所までしか歩けない）ため、水しぶきの演出はありません。
- 影のカスケード（CSM）とリアルタイム AO（GTAO）は、風で揺れる木・葉カードのシェーダと干渉するため未対応です。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm test         # 単体テスト（ground / train / config）
npm run build    # dist/ へビルド
```

`npm install` が使えない環境向けの、ビルド不要の代替確認手段は [tools/README.md](tools/README.md) 参照。画質向上・人物動作のリアル化の実装計画は [docs/plan-visual-quality-and-animation.md](docs/plan-visual-quality-and-animation.md) にまとめてあります。

URL パラメータ（動作確認用）: `?q=low|medium|high`（品質）、`?t=day|dusk|night`（時刻）、`?lang=en`、`?fps`（FPS 表示）、`?nogov`（解像度の自動調整を止める）。

## モデルを作り直す（Blender 5.2 が必要）

```bash
# 1) 風景・電車（PLATEAU/OSM のデータは blender/plateau_data/kamakura_koko.json に焼き済み）
blender -b --python blender/enoden_kamakurakokomae.py -- --no-character --no-blend --render none --web-export public/models
# 2) 人物（ウェブ用: サブディバイドを適用・平色マテリアル・5 アニメ。--save は付けない）
blender -b --python blender/character_male20s.py -- --stage anim --web-glb public/models/character.glb --no-verify --samples 8 --out /tmp/char
```

`blender/fetch_plateau.py` は PLATEAU（CityGML）と OSM から `kamakura_koko.json` を作り直すスクリプトです。
`blender/enoden_kamakurakokomae.py` は元の高精細レンダー用のシーン生成スクリプト（`--render both` で 1920×1080 の静止画）です。
